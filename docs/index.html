Edge Computing & IoT Rig

Physical Hardware Node (Raspberry Pi & ESP32)

Industrial IoT edge architecture running on Raspberry Pi 4 with GPIO-interfaced sensors and automatic motor interlock actuation on critical alarms.

🌡️ DHT22 Temperature & Humidity
  • • VCC: Pin 1 (3.3V) or Pin 2 (5V)
  • • DATA: Pin 7 (GPIO 4)
  • • GND: Pin 9 (Ground)
  • • Pull-up: 10kΩ between VCC and Data
  • • Range: -40°C to +80°C (±0.5°C)
📳 SW-420 Piezoelectric Vibration
  • • VCC: Pin 1 (3.3V)
  • • DO (Digital Out): Pin 11 (GPIO 17)
  • • GND: Pin 6 (Ground)
  • • Comparator: LM393 on-board
  • • Trigger: Shock & bearing resonance
⚡ ACS712 Current Sensor via ADS1115
  • • I2C SDA: Pin 3 (GPIO 2)
  • • I2C SCL: Pin 5 (GPIO 3)
  • • VCC: Pin 2 (5.0V)
  • • ADC Gain: 2/3x (±6.144V)
  • • Detects: Spindle motor overload
🛑 5V Relay Emergency Interlock
  • • VCC: Pin 4 (5.0V)
  • • IN: Pin 13 (GPIO 27)
  • • GND: Pin 14 (Ground)
  • • Function: Active-LOW contactor trip
  • • Actuation: Immediate safe shutdown

Documentation & Knowledge Base

Frequently Asked Questions

Key engineering details regarding feature leakage prevention, isotonic calibration, and false alarm economics.

How does this system prevent data leakage in time-series evaluation? ▾
Train and test splits are strictly partitioned by machine ID (GroupKFold), not by random cycle shuffling. This guarantees that test evaluation answers the authentic production question: "Can the model accurately predict pre-failure signatures on an asset it has never encountered during training?"
Why is Isotonic Probability Calibration essential for predictive maintenance? ▾
Standard gradient boosting algorithms output ranking scores rather than calibrated probabilities. By applying non-parametric isotonic regression on an independent validation set, predicted probabilities reflect true physical breakdown likelihoods, allowing operators to set economic cost-optimal alarm thresholds.
How does the Alert Engine mitigate alarm fatigue in industrial plants? ▾
The stateful Alert Engine uses dynamic severity band latches and cooldown periods. It suppresses redundant warnings within the same severity level while immediately escalating to an emergency work order if a machine's condition worsens from HIGH to CRITICAL.
Can this system operate on edge devices without internet connectivity? ▾
Yes. The entire inference bundle (calibrated scikit-learn pipeline, rolling window buffer, and threshold decision logic) runs self-contained on edge hardware like Raspberry Pi 4 or industrial IPCs with sub-12ms inference latency and zero cloud dependencies.
