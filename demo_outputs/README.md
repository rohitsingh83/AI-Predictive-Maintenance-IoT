# 📦 Demo Outputs & Operational Artifacts

This directory contains representative outputs, sample industrial work orders, API payloads, and telemetry snapshots generated by the **AI Predictive Maintenance IoT System**.

---

## 📂 Included Artifacts

1. **`sample_work_order_HDF.json`**
   * Generated upon detection of **Heat Dissipation Failure (HDF)** on machine `M08`.
   * Illustrates automated work order creation with technician instructions, risk score, diagnostic signature ($\Delta T < 8.6\text{K}$), and estimated downtime avoided ($36,000).

2. **`sample_work_order_TWF.json`**
   * Generated upon detection of **Tool Wear Failure (TWF)** on machine `M14`.
   * Flags tool wear exceeding 245 minutes with elevated cutting friction and recommends cutting insert replacement.

3. **`sample_api_prediction.json`**
   * Standard output format of the Flask `/predict` REST API endpoint.
   * Includes raw probability, calibrated probability, severity band (`LOW` / `MEDIUM` / `HIGH` / `CRITICAL`), and root-cause physics drivers.

4. **`fleet_health_snapshot.json`**
   * Live fleet status across all 30 monitored industrial machines ($M01$ through $M30$) with individual health indices, vibration RMS, temperature, and maintenance priorities.

---

## 🧪 How to Generate Fresh Outputs

* **Regenerate Live Work Orders:**
  ```bash
  python main.py simulate
  python main.py train
  python -c "from src.alert_system import replay_history; replay_history()"
  ```
  This updates `outputs/live_alerts.csv` and `outputs/alert_lead_time_report.csv`.

* **Generate High-Resolution Figures:**
  ```bash
  python main.py visualize
  ```
  Writes 17 publication-quality plots to `images/`.

* **Generate Interactive Operator Dashboard:**
  ```bash
  python main.py dashboard
  ```
  Generates `outputs/dashboard.html`.
